CARUS Creator Workspace

Development preview. CARUS is a local desktop workspace accessed through a browser on the operator’s computer.

What it does

CARUS combines social profile management, local media organization, messaging workflows and account analytics. It also supports local media categories intended for adults. The public documentation site does not host those materials.

TikTok integration

The planned integration uses TikTok authorization to read an authorized account’s profile, account statistics and public video information. The integration is under development and intended for testing using authorized accounts. TikTok has not approved or endorsed CARUS.
