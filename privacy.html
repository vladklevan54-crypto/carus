Privacy Policy

Draft: this policy describes the current local architecture and intended TikTok integration. Review it against the implemented integration before publishing or using it with real accounts.

Data and purposes

CARUS can store locally entered account information, analytics, media and correspondence from supported services. The planned TikTok integration requests permission to read basic profile information, profile details, account statistics and public video information. These data are intended for displaying account information and analytics in CARUS.

Storage and sharing

CARUS is designed to store application data on the operator’s computer. Connected services receive requests necessary for their integrations; TikTok authorization and API requests are handled by TikTok. This public documentation website does not receive CARUS account tokens or local media. GitHub Pages hosting is subject to GitHub’s own privacy practices.

Access and deletion

The operator can revoke third-party authorization in the relevant platform’s account settings. Revocation does not itself delete previously downloaded local data. Local records and backups must be managed separately. Contact the operator to request access, correction or deletion of data they control.

Security and retention

The operator must secure the device, credentials and backups. Data may remain locally until removed by the operator. No fixed retention period or guaranteed encryption is represented by this draft.
